# Hand work to the next session

Write a card so a new contributor can identify its outcome, take the first
step, and check completion. Include decisions, constraints, and open questions
that affect those actions. A short card may need only a few sentences.

At completion, record the outcome, checks actually performed, and limits of
the evidence. Identify direct consumers by link when safe. Read each affected
card and integrate the smallest useful finding beside the action, decision,
or acceptance check it changes. Link back to the source and summarize enough
to start from the consuming card alone.

On retries, reread cards and their relationships, apply only missing edits,
then verify both ends. Report any unfinished update.

For example, when archive-format issue #40 closes, its handoff to reader issue
#41 can say that an empty archive is valid and was tested. On #41, link #40
and add a reader check for an empty archive. This finding can be used
immediately.
